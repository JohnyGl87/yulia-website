## איך הטופס עובד — בלי שירות צד ג'

אתר סטטי לא יכול לשלוח מייל בעצמו, ובכוונה לא השתמשנו בשום שירות חיצוני.
במקום זה: המבקר ממלא את הטופס, ובלחיצה על "שליחה בוואטסאפ" (או "שליחה במייל")
נפתחת אצלו האפליקציה שלו עם ההודעה **כבר מוכנה בפנים**, והוא רק לוחץ שלח.

**היתרונות:** אפס הרשמות, אפס עלות, אפס תלות בגורם חיצוני, ואף פרט אישי לא
נשמר בשום שרת. בישראל וואטסאפ גם ממיר טוב יותר מטופס רגיל.

**החיסרון:** הפנייה נשלחת מהחשבון של הפונה, כלומר הוא רואה אותה לפני השליחה
ויכול לוותר באמצע. אם בעתיד תרצו טופס ש"נשלח לבד" ישירות למייל — אפשר להוסיף
שירות חינמי כמו Web3Forms בשינוי קטן ב-`app.js`.

## פרסום (Cloudflare Pages)

האתר סטטי לגמרי — **אין שלב build**. בהגדרות פרויקט Cloudflare Pages:

- Framework preset: **None**
- Build command: **(ריק)**
- Build output directory: **`/`**

כל `git push` לענף `main` מפרסם אוטומטית תוך כדקה.

Cloudflare מגיש כתובות נקיות, כלומר `/en.html` זמין גם כ-`/en`,
ו-`/lecture.html` כ-`/lecture`. הקישורים בין העמודים משתמשים בסיומת המלאה
(`./en.html`) כדי שהאתר יעבוד גם בפתיחה ישירה מהמחשב.
